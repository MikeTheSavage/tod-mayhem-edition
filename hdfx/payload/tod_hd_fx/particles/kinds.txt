# TOD HD: which particle sprites are SMOKE (lit smoke, `part_lit`) and which are HEAT SOURCES (heat haze, `heat_haze`).
#
# One line per sprite:  <manifest key>  smoke|heat
# The key is the sprite's name in manifest.txt beside this file (the texture's own leaf name). It is matched
# EXACTLY (case ignored) against the manifest line whose SHA-256 matched the texture the game bound -- so a key here
# is an identity, not a word to search for. A key that no manifest line has is reported in todhd_fx.log at start-up.
# Read when the game starts. Delete this file and the DLL uses the same table, built in.
#
# The blend at the draw still decides: a `smoke` sprite is lit only where the game draws it ALPHA-BLENDED (never
# additive: an additive sprite has no unlit level to scale), and a `heat` sprite makes heat only where the game draws
# it ADDITIVE.
#
# Built 2026-09-22 (partfix, KEEP.md 22.7) from the 163 keys of the installed particle manifest and the draw census of
# a real map09 session (work\research\vfx\data\draw_states.md). Census draw counts in brackets.
#
