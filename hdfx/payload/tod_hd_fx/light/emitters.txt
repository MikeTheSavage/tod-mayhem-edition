# name   the texture's key LEAF, exactly as the particle manifest (particles\manifest.txt: `fire`) or the material
#        class map (light\classes.txt: `parkinghouselamps`) names it.  `*<class>` matches every texture of that

# kind   fire   the fire and explosion sprites.  One quad per particle, each with its own world matrix; the sprites

#        flash  a muzzle flash: on at once, gone within a few frames, as strong as its draw's TFACTOR alpha.

#        lamp   a lamp, a glare billboard, a sign: a steady light at the draw's own world position.  The engine
#               frustum-culls, so a lamp stays lit for `emissive_persist` seconds after it was last drawn.
#        engine only for `*engine`.  The engine's own lights are applied per draw, only to the lit objects the
#               engine enabled them for, at the engine's own strength (1/Attenuation0) and attenuation.
# The intensity multiplies the colour (and `emissive_intensity` multiplies everything); the range is where the light
# reaches exactly zero (x `emissive_range`).  A draw whose world matrix has no translation (level geometry batched in
# world space) has no position of its own and is never a source, whatever its texture.
